# ANTSDR OS

Community-maintained firmware for MicroPhase ANTSDR software-defined radios.

## Supported Hardware

Current hardware support status:

| Device | Status |
| --- | --- |
| E200 | 🚧 Planned |
| E310 | ⚠️ Not Verified |
| E316 (E310v2) | 🚧 Planned |

> [!NOTE]
> Entries marked **Not Verified** are expected to work, but have not yet undergone hardware validation. Hardware testing contributions are welcome.
